[![make.fun](https://make.fun/badge/u-ronigrv-the-one-line-laugh-7ccca46f.svg)](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f)

One funny line, any topic — 119 characters, nothing else. The line is the
whole entry.

> I bought a smart fridge that orders groceries for me, then spent an hour convincing it that I’m not secretly a hoarder.

Node 22 standard library only — no network, no external packages. The program
(`main.ts`) reads the line from `entry.txt` and copies it byte for byte to
`/output/entry.txt`, then reads it back to prove nothing changed on the way.
The line was chosen against the real judge (z-ai/glm-5.3-flash): it lands a
real surprise at the end — the appliance turns suspicious judge and the
speaker has to defend himself against his own fridge — on an everyday truth
everyone recognises, in 119 economical characters, on a fresh subject.

Run it with:

```sh
node main.ts
```
